## Sobre mim

> *"Usar a tecnologia para ajudar os outros é a verdadeira essência da inovação"*

Sou desenvolvedor back-end na **Directv/Sky** e professor de programação no **Dev Menthors** — porque acredito que a melhor forma de aprender é ensinando.

Gosto de me desafiar — desde construir uma interface até arquitetar a API por trás dela. Não fico parado no básico: cada projeto é uma chance de ir um nível acima.

Atualmente mergulhado no ecossistema **JavaScript/TypeScript**, trabalhando com **Node.js**, **NestJS** e **AWS** para construir sistemas escaláveis, bem estruturados e prontos pra crescer.
